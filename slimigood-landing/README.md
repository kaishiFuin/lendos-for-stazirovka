# SlimiGood Landing Prototype

Одностраничный лендинг SlimiGood, собранный на Vite + React + TypeScript + TailwindCSS. Контент и логика соответствуют техническому заданию: A/B-варианты, квиз, калькулятор, таймер скидки, exit-intent модал и клиентская аналитика без реальных сетевых запросов.

## Старт проекта

```bash
npm install
npm run dev
```

## Продакшен-сборка

```bash
npm run build
npm run preview
```

## Тестирование

```bash
npm run test
```

## Архитектура

- `src/App.tsx` — корневой компонент и маршрутизация A/B-вариантов.
- `src/components/` — независимые блоки лендинга и вспомогательные UI-компоненты.
- `src/lib/` — бизнес-логика: аналитика, A/B, валидации и калькулятор.
- `src/i18n/ru.json` — заглушка локализации.
- `tests/calc.test.ts` — модульные тесты калькулятора.

## Примечания

- Все медиа подключаются по внешним HTTPS-ссылкам.
- Фавикон — встроенный SVG data URI.
- Максимальный размер бандла контролируется разделением кодовой базы (ленивая загрузка квиза и FAQ).
- GTM/аналитика подключается через `lib/analytics.ts` (GTM контейнер вставляется отдельно).
