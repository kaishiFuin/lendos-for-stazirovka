# SlimiGood Landing (Prototype)

SlimiGood — одностраничный прототип посадочной страницы, собранный на связке Vite + React + TypeScript + Tailwind CSS. Репозиторий содержит только текстовые файлы, все изображения подключаются по внешним HTTPS-ссылкам.

## Возможности
- Два A/B-варианта героя (скидка с таймером и квиз) через параметр `?v=A|B` или сохранение выбора в `localStorage`.
- Дневной дедлайн скидки с локальным сохранением.
- Квиз на 5 вопросов с прогресс-баром, мок-обработка заявок и логирование событий аналитики.
- Калькулятор ИМТ и прогноз снижения веса на 28 дней.
- Липкий CTA на мобильных, всплывающие уведомления и exit-intent модал с валидацией форм.
- Локальное хранилище для лидов и атрибуции UTM-меток.
- Vitest-покрытие ключевой бизнес-логики (калькулятор).

## Требования
- Node.js 18+

## Скрипты
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run test`

## Примечания
- Вся графика — через `https://placehold.co` или inline SVG.
- Файл PDF-дневника в оффере ведёт на заглушку Google Drive.
- Перед релизом подключите реальный контейнер GTM в `index.html`.
