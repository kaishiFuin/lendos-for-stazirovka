# SlimiGood Landing (Prototype)

Одностраничный лендинг SlimiGood, собранный на Vite + React + TypeScript + TailwindCSS. Все изображения подключены по HTTPS-ссылкам, бинарных файлов в репозитории нет.

## Старт разработки

```bash
npm install
npm run dev
```

## Сборка и предпросмотр

```bash
npm run build
npm run preview
```

## Тесты

```bash
npm test
```

## Примечания

- Ограничение по размеру бандла: целимся ≤200 КБ gzip после `vite build`.
- A/B-логика фиксирует вариант на 7 дней, либо позволяет указать `?v=A` или `?v=B`.
- Все формы работают в мок-режиме: данные валидируются, задержка отправки 1.5–2.5 секунд, заявки логируются в `localStorage` и `console`.
- Фавикон подключён через data URI, шрифт — Inter с Google Fonts.
- GTM-контейнер вставлять в `index.html` вместо комментария `// вставить GTM контейнер`.
