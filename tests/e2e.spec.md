# SlimiGood E2E Checklist

1. Запустить `npm install` и `npm run dev`, убедиться, что лендинг открывается без ошибок.
2. Проверить StickyBar: появляется через 3 секунды, содержит CTA «Получить SlimiGood со скидкой 50%».
3. Герой-блок: A/B варианты A и B подставляются из `useABVariant`, CTA ведёт к форме.
4. Социальные доказательства: логотипы клиник отображаются в SVG-формате, отзывы бегут по марке.
5. Оффер 4U: проверить таймер, счётчик, гарантии.
6. Блок «Преимущества»: три карточки с иконками Lucide.
7. Слайдер «До/После»: SVG-иллюстрации, ползунок реагирует на перетаскивание.
8. «Как это работает»: шаги с иллюстрациями.
9. «Состав»: вкладки переключаются, инфографика текстом.
10. Бегущая строка отзывов: анимация бесконечная.
11. Цены: три тарифа, кнопки ведут к форме.
12. Гарантия: блок с подписью основателя.
13. FAQ: аккордеон из Headless UI.
14. Форма лида: валидация, отправка в `/api/leads`, события аналитики.
15. Всплывающие виджеты: FloatingMessengers, Timer, ExitIntent, SpinnerGame.
16. SEO: метатеги, JSON-LD, robots и sitemap доступны.
17. Выполнить `npm run test:no-binaries` перед PR.
